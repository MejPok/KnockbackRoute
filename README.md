This is an early prototype of a wanna-be game.
This is a knockback absed 2d topdown game where u speedrun the dungeon in the leastpossible time, while dodging obstacles and even using them to your advantage.
Shoot backwards to launch yourself to gain speed, use hook to go easily around corners. And good luck with doors c:

Press Space to shoot,
Use mouse to aim.
Hold E to hook.
Press ESC to pause or change map.

Bugs are common feature of this game, if u get stuck or the level is impossible go into ESC menu and choose different seed.
